Stop renting your reading list.

SubZero Vault keeps your articles, bookmarks and highlights on a machine you own. It ranks searches the way a search engine does, brings highlights back on a schedule, and shows what your monthly bills add up to.

Open the vault Get the Compose file

Prices on this page are editable examples. Your own bill is the one that counts.

Four commands to your own copy

Clone it, start it, open it. The server needs nothing but Docker. Data lands in a folder next to the Compose file and backups run on a schedule you can change.

git clone https://github.com/draarivpatel-ui/subzero-vault
cd subzero-vault
docker compose up -d
open http://localhost:8090

      Two ways to run it

      In this browser

      Everything on this page runs here. Articles, highlights and review dates sit in this browser's local storage, so clearing site data clears the vault. Export your bookmarks or JSON whenever you like.

      The search, the review scheduler, the importer and the calculator are the same code the server uses.

      On a server you own

      A single Python file, standard library only, with SQLite for storage and scheduled backups. Point this page at it from the connect drawer, or open the server's own address, which serves the same app.

      Browsers differ on whether an https page may call a plain http address on your own machine, and some ask for permission first. If yours blocks it, open the server's own address instead, which serves this same app.

      What it does not replace

      Rocket Money's bank sync and bill negotiation need access to your accounts, and this project does not touch that. The audit here is a calculator you fill in by hand.

      Readwise Reader's feed reader, newsletters and mobile apps are also out of scope. Saved pages, highlights and review are in.
